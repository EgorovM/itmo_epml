# Развертывание ClearML Server

## Локальное развертывание

### Через Docker Compose

```bash
# Запустить все сервисы
make clearml-up

# Проверить статус
make clearml-status

# Просмотреть логи
make clearml-logs
```

### Компоненты

- **MongoDB** - база данных (порт 27017)
- **Redis** - кэш и очереди (порт 6379)
- **Elasticsearch** - поиск (порт 9200)
- **ClearML Server**:
  - API Server (порт 8008)
  - Web Server (порт 8080)
  - Files Server (порт 8081)

## Настройка аутентификации

1. Откройте http://localhost:8080
2. Войдите с учетными данными по умолчанию:
   - Логин: `admin`
   - Пароль: `admin`
3. Создайте API ключи в Settings → Workspace
4. Настройте переменные окружения:

```bash
export CLEARML_API_ACCESS_KEY="your_key"
export CLEARML_API_SECRET_KEY="your_secret"
```

## Продакшн развертывание

Для продакшн развертывания:

1. Используйте внешнюю базу данных (PostgreSQL вместо SQLite)
2. Настройте HTTPS
3. Используйте секреты для API ключей
4. Настройте мониторинг и логирование

## Масштабирование

Для масштабирования:

- Используйте несколько воркеров
- Настройте очереди задач
- Используйте распределенное хранилище
