# Отчеты об экспериментах

## Автоматическая генерация отчетов

Отчеты об экспериментах генерируются автоматически из результатов MLflow с графиками и визуализациями.

### Генерация отчета

```bash
# Сгенерировать отчет из MLflow
make report-generate

# Или напрямую
python src/reports/generate_experiment_report.py
```

Отчет будет сохранен в `docs/reports/experiment_report.md` с графиками в `docs/reports/figures/`.

## Структура отчета

Отчет включает:

1. **Сводка** - общая статистика экспериментов:
   - Лучшая, средняя, минимальная точность
   - Стандартное отклонение
   - Общее количество экспериментов

2. **Визуализации** (3 типа графиков):
   - График сравнения точности (Top 10 моделей)
   - Scatter plot: Train vs Test Accuracy
   - Гистограмма распределения точности

3. **Сравнительная таблица** - топ экспериментов с ранжированием

4. **Детальные результаты** - параметры и метрики для топ-10 моделей

## Сравнительные таблицы

Автоматически генерируются таблицы сравнения с ранжированием:

| Rank | Algorithm | Accuracy | Train Accuracy | Status |
|------|-----------|----------|----------------|--------|
| 1 | RandomForest | 1.0000 | 1.0000 | FINISHED |
| 2 | SVM | 1.0000 | 0.9750 | FINISHED |
| 3 | KNN | 1.0000 | 0.9667 | FINISHED |
| ... | ... | ... | ... | ... |

Таблица включает:
- **Rank** - позиция в рейтинге
- **Algorithm** - название алгоритма
- **Accuracy** - точность на тестовой выборке
- **Train Accuracy** - точность на обучающей выборке
- **Status** - статус выполнения эксперимента

## Автоматическая генерация

Отчеты генерируются автоматически:

- При запуске экспериментов через `make run-experiments`
- По запросу через `make report-generate`
- Могут быть интегрированы в CI/CD pipeline
- После завершения DVC pipeline
