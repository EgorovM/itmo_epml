# Отчеты об экспериментах

## Автоматическая генерация отчетов

Отчеты об экспериментах генерируются автоматически из результатов MLflow.

### Генерация отчета

```bash
# Сгенерировать отчет из MLflow
python src/reports/generate_experiment_report.py
```

Отчет будет сохранен в `reports/experiment_report.md`.

## Структура отчета

Отчет включает:

1. **Сводка** - общая статистика экспериментов
2. **Таблица сравнения** - топ экспериментов
3. **Детальные результаты** - параметры и метрики

## Пример отчета

Отчеты сохраняются в директории `reports/` в корне проекта.

## Визуализации

Графики и визуализации сохраняются в директории `plots/`:

- Распределение данных
- Сравнение метрик
- Графики обучения

## Сравнительные таблицы

Сравнительные таблицы генерируются автоматически и включают:

- Алгоритм
- Accuracy (тест)
- Train Accuracy
- Статус выполнения
