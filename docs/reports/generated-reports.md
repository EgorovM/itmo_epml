# Сгенерированные отчеты

## Автоматическая генерация

Система автоматически генерирует отчеты об экспериментах с:

- ✅ Графиками и визуализациями
- ✅ Сравнительными таблицами
- ✅ Детальной статистикой
- ✅ Параметрами моделей

## Примеры отчетов

### Отчет об экспериментах

```bash
# Сгенерировать отчет
make report-generate
```

Создается файл `docs/reports/experiment_report.md` с:

1. **Сводной статистикой**
2. **Графиками**:
   - Сравнение точности моделей
   - Train vs Test Accuracy
   - Распределение метрик
3. **Сравнительными таблицами**
4. **Детальными результатами**

### Структура файлов

```
docs/reports/
├── experiment_report.md      # Основной отчет
└── figures/                   # Графики
    ├── accuracy_comparison.png
    ├── train_vs_test.png
    └── accuracy_distribution.png
```

## Интеграция в документацию

Отчеты могут быть включены в документацию MkDocs:

```markdown
![Accuracy Comparison](figures/accuracy_comparison.png)
```

## Автоматизация

Отчеты можно генерировать автоматически:

- После завершения экспериментов
- В CI/CD pipeline
- По расписанию
