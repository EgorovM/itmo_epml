# Сравнение моделей

## Автоматическое сравнение

Используйте скрипт для сравнения моделей:

```bash
# Сравнить эксперименты MLflow
make compare-experiments

# Или напрямую
python src/experiments/compare_experiments.py
```

## Сравнение через MLflow UI

1. Запустите MLflow UI:
   ```bash
   make mlflow-ui-db
   ```

2. Откройте http://localhost:5000

3. Выберите эксперименты для сравнения

4. Просмотрите метрики и параметры

## Сравнение через ClearML UI

1. Запустите ClearML Server:
   ```bash
   make clearml-up
   ```

2. Откройте http://localhost:8080

3. Используйте встроенные инструменты сравнения

## Метрики сравнения

Основные метрики для сравнения:

- **Accuracy** - точность классификации
- **Train Accuracy** - точность на обучающей выборке
- **F1 Score** - гармоническое среднее precision и recall
- **Confusion Matrix** - матрица ошибок
